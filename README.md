# Description
Project Bellum is a text-based RPG made in Python designed to help players relieve
stress and increase puzzle-solving skills. You uncover a world full of mysteries as you interact with
people, collect items, get stronger, and fight enemies.

# Disclaimer
This project only works properly in Windows.
Versions other than Python 3.13.9 might be unstable.

# How To Install
- Download all of the files
- Download PyCharm and the PyGame library
    - PYCHARM: https://www.jetbrains.com/pycharm/download/?section=windows
    - PYGAME ( Run in PyCharm terminal ): pip install pygame
- For the Python interpreter, make a virtual environment using PyCharm. Use Python 3.13.9.

# How to Run
- Go to PyCharm terminal and full-screen it.
- Run "python main.py" and enjoy!
- Check the information out before playing the game for a smoother experience.

# Controls
- Press the corresponding key of the action you want to do
- Press H for help or information
- Press X to exit the game
- Press S to save the game
- Press L to load a savefile
- Press I to access inventory
